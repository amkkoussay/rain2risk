# Rain2Risk Phase 6.5 Data Integrity Report

No point-level validation was computed. The source events name regions such as Tunis, Ariana, Manouba, or North Tunis, but do not provide exact event coordinates. The old hand-made coordinates were removed from point validation. Unknown flood status is kept as `NA`, not as no flood.

The historical event and rainfall files remain available for later polygon-level or station-level validation. The production Risk Engine was not changed.
